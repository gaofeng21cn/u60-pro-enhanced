## 安装风险

需要 root ADB，修改 `/data` 程序、`/etc/init.d` 与 `/etc/rc.local` 启动配置，可能造成失联、热点异常、启动失败、耗电、充电异常或需要人工恢复。原厂 OTA/恢复出厂可能覆盖启动项或使依赖不兼容；本项目不提供完整 EDL/Firehose 救砖方案，不提供固件分区备份。不要使用 opkg 强装不匹配的内核模块。

网页复用原厂 HTTP 管理通道；原厂管理密码和会话安全边界依旧存在。只在可信 LAN/私有 Tailscale 访问，不映射公网。订阅和中继密码必须由使用者自己输入；不要使用公开 issue 传递。

## 建议逐项验收

1. 不启用代理与组网，验证热点、原厂网页、屏幕和电源键。
2. 配置 Clash 后测试真实业务和规则命中，保留直连恢复入口。
3. Tailscale 先测本机，再测外部网络访问下属设备，管理端授权由本人完成。
4. USB 与中继分别测，不同时改变两个上游；观察下游真实联网和回退。
5. 最后测试休眠、按键唤醒与待机耗电；没有稳定基线前不启用深度待机。
6. 充电控制仅在独立硬件验收后启用；公开包不提供伪造验收开关。

## v0.1.3 新增验证范围

三主题持久化、非法值和保存失败处理；五菜单原生图标、点击范围、滚动边缘与长列表；模拟数小时休眠计时差、唤醒时 uptime 跳变、真实心跳停滞/缺失的看门狗保护均纳入回归。玻璃主题为静态效果，未完成整夜功耗对照。本次不扩大双频中继、充电、第二台设备首装等旧有验收边界。

开发机本轮已核对安装二进制哈希、海雾玻璃持久值、LCD 缓冲画面、原厂/新 UI 来回切换及持续心跳；Clash/Tailscale 进程、启动标识和其余设置保持不变。图标/点击区与三主题切换逻辑通过主机测试；用户对新版实体触摸手感和长待机结果仍可继续反馈。
