# 使用与切换

- **屏幕**：单击电源亮/灭屏；双击电源在新 UI 与原厂 UI 之间切换；长按显示电源菜单。熄屏后触摸不唤醒。长按后的重启行为受原厂固件影响，见风险清单。
- **网页**：连接 U60 热点/手动 LAN，访问路由器地址（原厂默认 `http://192.168.0.1/`），使用自己的原厂管理密码登录，再点侧栏末尾的“增强功能”，或登录后打开 `/#u60_enhanced`。刷新浏览器以更新缓存；没有独立默认密码。增强功能侧栏包含概览、网络、Clash、Tailscale、电源、工具；热点、APN、路由/DNS/DHCP/防火墙、短信及套餐设置统一使用原厂菜单。屏幕的独立流量账本仍保留，不与原厂套餐数据自动同步。
- **共用设置**：屏幕和增强网页使用同一控制层与操作锁；操作进行中等待结果再重复。原厂设置仍可能改变底层状态，扩展会读取实际值，但不保证任意第三方程序同时写入都无冲突。
- **切回原厂 UI**只切显示与输入，并不停止 Clash、Tailscale 或所有协调服务。停止代理请用统一服务/路由入口；Tailscale 按需单独关闭。
- **Wi-Fi 中继（v0.1.2）**：保留 5G 主热点、关闭访客热点，USB 设为 LAN；自身 2.4G 热点可同时开启。屏幕“网络 → Wi-Fi → 连接 / 更换上游 Wi-Fi”，或网页“增强功能 → 网络”选择上游。列表按 2.4G/5G 分开，选择一个上游并在设备界面输入密码；凭据留在本机受限配置。更换时不必先手动断开；信道调整会使对应热点客户端短暂重连。热点和 LAN 下游共用当前出口，掉线会自动回退蜂窝，不是禁止 SIM 消耗的模式。非 DFS 信道与限制详见 [中继说明](WIFI-RELAY.md)。旧 v0.1.1 Release 仍要求关闭 2.4G 热点后连接 2.4G 上游。
- **USB 网络**：外接 USB 转以太网适配器时，LAN 给下游供网，AUTO 探测上级路由器的 LAN 口。数据线直连电脑使用独立的 RNDIS/ECM 功能，不能用 LAN 角色或 ADB 连通代替网卡枚举验证。屏幕与网页显示当前直连协议、主机识别及网桥状态；Mac 直连尚未通过验证，在线 ECM/RNDIS 切换暂不可用。若切换旧版脚本后 USB 消失，保持设备开机，先重插数据线并检查热点/原厂网页；未恢复管理通道前停止设备写入。不要依赖已经消失的 ADB 执行回退。
- **Clash / Mihomo**：首次安装保持 DIRECT；B31 首装不会自动启动代理服务。按安装说明添加自己的 Mihomo proxy-provider 订阅、更新并启用代理。节点选择会定位当前规则/全局流量路径上的具体策略组；网页和屏幕均显示可选节点，网页切换后会回读确认。切换外层策略组与切换叶子节点是不同操作；标注“当前使用”的组对应当前生效路径。关闭代理路由后直连。订阅删除若仍被选中会拒绝，先换选择。公开默认组无付费节点，不能不加订阅直接获得代理能力。
- **节点快速入口**：Clash 网页默认进入“节点”。当前、收藏和最近使用的节点排在其他节点之前，同一节点只显示一次；其他节点每次展开 12 个，搜索覆盖当前策略组的全部节点。收藏和最近使用保存在设备本机并由屏幕与网页共享；收藏最多 20 个、最近使用 5 个，离线或已从订阅移除的节点不会出现在快速入口。节点行的“查延迟”按钮是连通延迟测试，不是带宽测速。
- **自动选择**：可在订阅下新增 `自动选择`（`url-test` 策略组），按连通延迟自动切换，初始为 5 分钟间隔、50 ms 容差和按需检测。启用后网页与屏幕仍可手动固定节点；确认自动选择行为符合预期前保持手动固定。
- **分流模式**：规则分流、全局代理与直连通过控制层校验并回读。GLOBAL 仍指向直连时，全局代理会被拒绝并提示先选择可用节点，避免界面显示“全局代理”而实际直连。
- **代理状态与覆盖自检**：屏幕“代理 → 实际代理状态”和网页“Clash → 代理概况 → 查看接管详情”分别显示核心是否运行、流量是否已接管、当前模式与 `MATCH / GLOBAL → 策略组 → 节点` 路径。网页自检位于“连接与诊断”，规则集更新位于“分流规则”。屏幕自检位于“代理 → 代理管理”，点“代理覆盖自检”会回读实际转发规则：IPv4 TCP 与 DNS 已生效、UDP 与 IPv6 是否代理、UDP 443 是否被拒绝，并在存在 IPv6 默认路由时提示客户端可能绕过代理。代理覆盖只覆盖 IPv4 TCP 与 DNS；UDP 443 被拒绝以避免静默直连，443 以外的 UDP 与 IPv6 仍按直连处理。自检只读取，不修改服务状态。订阅列表显示可用节点数、用量、到期与超过两个更新周期的提示；用量缺失时不会伪造数字。
- **Tailscale**：网页分为“组网与访问”“互联网出口”和默认折叠的“高级组网设置”；账号与高级管理按需展开。本机组网停止时，设备列表会明确标为最近获取的状态。本机在线与双向下属设备互通是不同验收项；后者需要 TUN、设备转发、发布/批准路由和正确 ACL/Grant。退出节点可能改变默认出口，与 Clash 共存应分步骤验证。
- **待机**：网页把充电与待机设置、实际电池与供电状态分开呈现；暂不可用项直接显示原因。公开默认普通模式；深度模式会在符合无人连接等条件、原厂进入休眠时暂停原先运行的 Clash/Tailscale，按电源键后恢复。因此深度休眠时不能保证远程可达。USB 接入/充电条件下原厂可能保持工作，不能把“搜到热点”直接当作故障。
- **电量控制**：界面提供 80/90/100% 上限、5%回差与手动模式。新设备默认锁定，需独立验证电流、外电在线、停充和恢复后才能使用。不能声称物理隔离电池或支持拔电池运行，不应绕过验收锁。

屏幕首页集中显示上游、实际出口、速率、蜂窝用量和已选节点；“已选节点”不代表当前正在走代理，以“出口”和“实际代理状态”为准。Wi-Fi、USB 与已连接设备使用至少 44 像素高的触控入口，CPU、内存、温度和运行时间在“设置 → 电源与屏幕”查看。代理页先显示可展开的实际状态、开关、模式、节点与收藏；订阅、规则、连接和诊断归入“代理管理”。组网页优先显示连接状态与访问开关，设备、互联网出口和高级项归入“组网管理”。无活动连接时显示空状态，不能触发清理；组网停止后，地址和设备列表明确标为最近记录。管理页左上角返回本级入口，底栏可直接切换栏目。选项列表对能明确匹配的当前值标记“当前”，需要确认的选择会在确认页显示所选内容。

其他屏幕可操作项优先排列，禁用能力归入“暂不可用”并保留原因；电池页的实际状态、策略状态和验收信息集中到“电池与待机详情”。三套主题布局和操作保持一致，调整的是颜色与可读性。

## 海雾玻璃主题（v0.1.3）

屏幕「设置 → 电源与屏幕 → 界面主题」可选择曜石彩卡、纸白蓝、海雾玻璃，选中后保存到设备；重开新 UI 保留选择。底栏五项均有原生图标与文字。海雾玻璃为静态渐变与透明合成，没有持续动画或实时模糊，不改变待机唤醒条件。网页版保持自己的样式。
