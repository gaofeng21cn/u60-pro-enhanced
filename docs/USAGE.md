# 使用与切换

- **屏幕**：单击电源亮/灭屏；双击电源在新 UI 与原厂 UI 之间切换；长按显示电源菜单。熄屏后触摸不唤醒。长按后的重启行为受原厂固件影响，见风险清单。
- **网页**：连接 U60 热点/手动 LAN，访问路由器地址（原厂默认 `http://192.168.0.1/`），使用自己的原厂管理密码登录，再点侧栏末尾的“增强功能”，或登录后打开 `/#u60_enhanced`。刷新浏览器以更新缓存；没有独立默认密码。增强页底部为概览、网络、Clash、Tailscale、电源、工具；热点、APN、路由/DNS/DHCP/防火墙、短信及套餐设置统一使用原厂菜单。屏幕的独立流量账本仍保留，不与原厂套餐数据自动同步。
- **共用设置**：屏幕和增强网页使用同一控制层与操作锁；操作进行中等待结果再重复。原厂设置仍可能改变底层状态，扩展会读取实际值，但不保证任意第三方程序同时写入都无冲突。
- **切回原厂 UI**只切显示与输入，并不停止 Clash、Tailscale 或所有协调服务。停止代理请用统一服务/路由入口；Tailscale 按需单独关闭。
- **Wi-Fi 中继（v0.1.2）**：保留 5G 主热点、关闭访客热点，USB 设为 LAN；自身 2.4G 热点可同时开启。屏幕“网络 → Wi-Fi → 连接 / 更换上游 Wi-Fi”，或网页“增强功能 → 网络”选择上游。列表按 2.4G/5G 分开，选择一个上游并在设备界面输入密码；凭据留在本机受限配置。更换时不必先手动断开；信道调整会使对应热点客户端短暂重连。热点和 LAN 下游共用当前出口，掉线会自动回退蜂窝，不是禁止 SIM 消耗的模式。非 DFS 信道与限制详见 [中继说明](WIFI-RELAY.md)。旧 v0.1.1 Release 仍要求关闭 2.4G 热点后连接 2.4G 上游。
- **USB LAN**：屏幕网络 → USB 网口 → 选 LAN，再接下游电脑。AUTO 用于探测上级路由器的 WAN，不能代替手动 LAN。测 LAN 时关闭电脑 Wi-Fi/VPN；测 WAN 接上级 LAN 口而不是 WAN 口。上级与 U60 子网冲突可能导致失败。
- **Clash / Mihomo**：首次安装保持 DIRECT；B31 首装不会自动启动代理服务。按安装说明添加自己的 Mihomo proxy-provider 订阅、更新并启用代理。节点选择会定位当前规则/全局流量路径上的具体策略组；网页和屏幕均显示可选节点，网页切换后会回读确认。切换外层策略组与切换叶子节点是不同操作；标注“当前流量使用”的组对应当前生效路径。关闭代理路由后直连。订阅删除若仍被选中会拒绝，先换选择。公开默认组无付费节点，不能不加订阅直接获得代理能力。
- **Tailscale**：本机在线与双向下属设备互通是不同验收项；后者需要 TUN、设备转发、发布/批准路由和正确 ACL/Grant。退出节点可能改变默认出口，与 Clash 共存应分步骤验证。
- **待机**：公开默认普通模式；深度模式会在符合无人连接等条件、原厂进入休眠时暂停原先运行的 Clash/Tailscale，按电源键后恢复。因此深度休眠时不能保证远程可达。USB 接入/充电条件下原厂可能保持工作，不能把“搜到热点”直接当作故障。
- **电量控制**：界面提供 80/90/100% 上限、5%回差与手动模式。新设备默认锁定，需独立验证电流、外电在线、停充和恢复后才能使用。不能声称物理隔离电池或支持拔电池运行，不应绕过验收锁。

屏幕可操作项优先排列，禁用能力归入“暂不可用”并保留原因；电池页的实际状态、策略状态和验收信息集中到“电池与待机详情”。三套主题布局和操作保持一致，调整的是颜色与可读性。

## 海雾玻璃主题（v0.1.3）

屏幕「设置 → 电源与屏幕 → 界面主题」可选择曜石彩卡、纸白蓝、海雾玻璃，选中后保存到设备；重开新 UI 保留选择。底栏五项均有原生图标与文字。海雾玻璃为静态渐变与透明合成，没有持续动画或实时模糊，不改变待机唤醒条件。网页版保持自己的样式。
