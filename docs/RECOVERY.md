# 回退与保留数据

先双击电源切回原厂屏幕。切回屏幕不会停止网络扩展；需要完全回退启动项时用 USB 直连，进入该设备安装时使用的同一版本 `u60-prepared-private` 目录：

```sh
python3 deploy-from-computer.py restore-boot
```

脚本校验同一版本与安装记录，停用扩展自启动、卸载临时网页覆盖层并恢复安装前 `/etc/rc.local`；保存现有启动文件副本。**不删除 `/data` 中的订阅、Tailscale 身份或 Wi-Fi 凭据，也不承诺实时撤销全部网络规则**，当前进程需手动关机再开机后确认。原厂重启曾表现为关机，请在设备旁操作。不要把“已恢复启动文件”误认为已完成全部业务恢复。

启动备份位于 `/data/u60-install-backups/` 下对应版本目录。检查包丢失时，可用 root ADB 核对该目录的 `release-id`、`rc.local` 与 `status`，由理解启动结构的人手动恢复。不要删项目目录后再尝试恢复启动项。

安装失败的程序会保留在恢复目录 `incomplete/`，用于排查，不自动重新安装。已有安装不能用首装脚本覆盖；本项目已有安装使用[原地升级入口](INSTALL.md)，不支持任意第三方布局迁移。恢复出厂不是本项目建议的常规回退手段。

## 安装材料与备份空间

`/data/u60-packages/` 是上传的安装材料，`/data/u60-upgrade-backups/` 是逐文件校验的升级前程序备份，两者都不属于正在运行的程序目录。长期保留每次完整上传与每份升级备份会重复占用空间。清理前先把选定目录归档到受限的本机目录，核对归档中的每个文件与原校验清单一致，并重新检查当前安装版本未改变，再删除那一份设备目录。需要使用已清理的安装材料或备份时，先从归档恢复原目录并重新校验。

设备上至少保留首次安装的 `/data/u60-install-backups/`、`to-release` 与当前安装版本一致的升级备份，以及前一份已验证的升级备份。不要删除运行中的 `/data/u60-panel/`、`/data/u60-web/`、`/data/u60-clash/`、`/data/tailscale/` 或原厂数据目录来腾出空间；订阅、配置、策略偏好和身份不是可再生成的缓存。
