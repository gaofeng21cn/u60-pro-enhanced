# 文档导航

本目录按读者要解决的问题组织。根目录 [README](../README.md) 提供下载、安装和日常使用入口；本页指向各主题的唯一详细说明。

## 用户入口

- [当前产品基线](BASELINE.md)：本版本已经提供什么、明确不承诺什么。
- [安装与升级](INSTALL.md)：首次安装、原地升级、设备绑定和准备器要求。
- [日常使用](USAGE.md)：小屏、网页、代理、组网和网络功能的操作方式。
- [Mac USB 直连](MACOS-RNDIS.md)：B31 原生 ECM＋ADB 的使用、恢复和兼容边界。
- [Wi-Fi 接力](WIFI-RELAY.md)：2.4GHz／非 DFS 5GHz 上游、保存网络、回退和停止方式。
- [网络诊断](NETWORK-DIAGNOSTICS.md)：路由、DNS、HTTPS、代理和出口结果的含义。
- [恢复与清理](RECOVERY.md)：切回原厂、启动项回退、升级备份和空间维护。

## 开发与发布

- [产品目标](PLAN.md)：长期目标、产品原则和各能力的完成标准。
- [验证范围](VALIDATION.md)：当前实机、主机回归和仍缺证据的范围。
- [更新记录](CHANGELOG.md)：各公开版本的用户可见变化。
- [发布审查](RELEASE-AUDIT.md)：公开包、构建、秘密边界和发布回读。

设计目标、当前事实、操作流程和历史变化分别由上述文档维护。同一结论不在多个文件复制；主题文档与当前产品基线冲突时，应先修正真实实现和对应主题文档，再更新基线摘要。
