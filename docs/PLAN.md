# 产品目标与完成标准

U60 Pro Enhanced 的目标是把原厂 U60 Pro 增强为可靠、易用、可恢复的便携联网设备。小屏承担状态查看和常用操作，网页承担输入与高级管理；两端共享同一设置、动作和结果。项目保留原厂固件、热点、管理页和 ADB，不通过刷机或牺牲恢复能力换取扩展功能。

当前实现与验收边界由 [产品基线](BASELINE.md) 和 [验证范围](VALIDATION.md) 维护。本文件只定义稳定的产品目标和完成标准，不记录版本进度或设备快照。

## 产品原则

- **低认知成本**：小屏和网页使用“网络、代理、组网、电源、工具”等一致名称；界面先显示用户结果，再提供实现细节。
- **状态可信**：区分用户选择、正在应用、链路建立、获得地址和真实互联网可用；不能用进程存在或配置写入代替业务成功。
- **原厂共存**：保留原厂界面、热点、管理页、ADB 和恢复入口；增强功能失败时回到可管理、可联网的原厂基线。
- **按证据开放**：硬件写操作和可能失联的能力只在对应固件完成写入、回读和恢复验收后开放；未知固件默认拒绝。
- **配置私有**：订阅、节点、Tailscale 身份、设备标识、原厂材料和安装派生目录只存于设备或用户本机，不进入公开包。

## 核心联网

| 能力 | 完成标准 |
| --- | --- |
| 蜂窝与热点 | 热点客户端真实 HTTPS、保存设置后的服务恢复、代理启停和直连恢复均可独立验证。 |
| Wi-Fi 接力 | 2.4GHz 与非 DFS 5GHz 上游可扫描、保存、排序、关联、取得地址并向热点或 LAN 提供网络；停止后按策略恢复蜂窝，失败重试不丢密码。 |
| 代理 | 小屏和网页开关、模式和节点一致；启动遵循用户意图；界面区分核心运行、规则接管和真实出口，并明确协议覆盖边界。 |
| 组网 | 启停、登录状态、设备访问、子网转发和出口相关状态分别呈现；身份在升级后保留，关闭意图不会被配置存在覆盖。 |
| 网络诊断 | 路由、地址、DNS、默认出口、代理 HTTPS 和 TLS 分项报告；探测失败不擅自改路由，也不把局域网链路称为互联网成功。 |

## USB 与硬件协调

| 能力 | 完成标准 |
| --- | --- |
| USB 网卡 | LAN 与 AUTO 角色明确；只对已识别驱动和验收组合开放相应行为；断线和拔卡后恢复安全出口。 |
| Mac USB 联网 | Mac 使用一根数据线即可原生取得网络，无需安装驱动或运行终端命令；保留 ADB，启停、拔插和冷启动后自动恢复，失败时回到完整原厂 USB 组合。 |
| 供电与待机 | 与 USB 数据角色互斥关系明确；任何充电、供电方向或深度待机写操作都需要对应固件的写入、回读和恢复证据。 |

Mac USB 的首选实现是设备原生、macOS 免驱的 ECM＋ADB。NCM 或 Mac 用户态 RNDIS 工具只在原生路线被具体设备限制证伪时作为替代方案，不与已成立的原生路线并行增加用户负担。实现与恢复合同由 [Mac USB 直连](MACOS-RNDIS.md) 维护。

## 界面、性能与交付

| 能力 | 完成标准 |
| --- | --- |
| 小屏与网页 | 名称、导航、开关和确认语义一致；常用操作在小屏可达，复杂输入优先网页；刷新不打断输入，错误可修改后重试。 |
| 性能与资源 | 空闲、负载和屏幕状态可测；同名进程合计资源，进程重启不产生错误差值；设备空间保留升级和恢复余量。 |
| 安装与升级 | 支持的固件和设备身份双重绑定；准备、检查、安装、启动和升级状态分离；用户配置保留，失败恢复上一份可运行程序。 |
| 恢复与维护 | 双击切回原厂、ADB 和独立局域网 SSH 构成分层恢复路径；不依赖刷机、恢复出厂或分区写入。 |
| 发布 | 公开包由当前源码重建，包含安装文档和 SHA-256；设备私有材料不入包；源码、设备安装、真实业务和公开资产分别回读。 |

普通 UDP 和 IPv6 全量代理、企业 Wi-Fi、DFS/6GHz、认证门户自动处理、所有 USB 网卡/扩展坞兼容、任意固件和任意设备批次不自动成为核心承诺。只有产品基线明确纳入且取得相应证据后，才扩展当前合同。
