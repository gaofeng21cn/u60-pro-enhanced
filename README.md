# U60 Pro Enhanced · 自维护版

面向 U60 Pro 用户维护的**屏幕 UI + 原厂网页版增强**，运行在中兴 MU5250 国行原厂系统上。保留中兴系统、基带、Wi-Fi 驱动和原厂界面，不是 OpenWrt 固件，也不是整机刷机包。

## 本仓库的定位

本仓库以自有 `main` 作为维护主线，固件兼容、屏幕 UI、原厂网页增强和 Clash / Mihomo 使用体验都在这里持续演进。上游仓库保留为 `upstream`：通用、可复现的问题和改进会整理成 issue / PR 提交上游，但上游是否合并都不影响本仓库继续修复和更新。

准备工具分别校验国行 B28（`BD_FLYMODEMMU5250V1.0.0B28`、Linux `5.15.185-perf`）与国行 B31（`BD_CNMU5250V1.0.0B31`、Linux `5.15.194-perf`）的原厂文件指纹，并拒绝未知固件或错配安装包。B28 保持现有启动行为。B31 已在一台实机验证增强屏幕、双击电源键双向切换、原厂网页，以及手动配置并启用内置 Mihomo 后的代理和节点选择。B31 首装仍默认直连，不会自动启动网络协调服务；USB 网口、Wi-Fi 中继、待机维护、长时稳定性和完整回退仍须分别验收。它不是通用插件商店，也不提供 OpenWrt 固件或 LuCI。B28 的测试结果不代表 B31 的实机验收结果。


## 相比原厂增加了什么

| 模块 | 新屏幕 UI | 原厂网页版“增强功能” |
|---|---|---|
| 首页与显示 | 五个主页、流量/速率/时间/电池/信号/上游状态、主题和亮度 | 新增能力概览、底部分类导航 |
| Clash / Mihomo | 服务与分流开关、规则/全局模式、节点选择、测速、代理覆盖状态与自检 | 代理状态卡（核心、接管、模式、流量路径）、订阅用量与到期、策略组与节点、规则及本地规则、连接查看与关闭、代理覆盖自检；URL 脱敏 |
| Tailscale | 开关、模式、设备、子网互通、出口选择等 | 更完整设备清单、健康/版本/密钥到期、主机名、发布路由、网络诊断；管理端审批仍在 Tailscale 后台 |
| Wi-Fi | 2.4G/5G 分别开关、双热点共存中继、选择/更换上游及保存频段 | 同一中继入口；热点基础设置使用原厂菜单 |
| USB 网口 | 手动 LAN 与 AUTO 上游 WAN 识别、状态与回退 | 同一角色设置与状态 |
| 电源与待机 | 保留电源键操作；充电/直供、待机服务策略与详情 | 同步充电状态和控制；危险能力按本机验收结果锁定 |
| 其他 | 流量账本、蜂窝信息与部分高级设置 | 原厂页面继续承担原有管理功能；增强页不宣称覆盖所有社区端点 |

**边界：** B28 既有透明代理验证覆盖 IPv4 TCP 与 DNS；B31 实机已验证手动配置后的代理可用和节点切换回读，但普通 UDP、IPv6 全量代理、全面防泄漏和长期负载仍未完成验证。屏幕和网页把“核心在运行”与“流量已接管”分开显示，“代理覆盖自检”由网络协调脚本回读实际转发规则，会直接说明 UDP 与 IPv6 未代理，并在存在 IPv6 默认路由时提示客户端可能绕过代理。Tailscale 的双向子网访问需要管理端批准路由和访问策略，不会自动放开账号权限。v0.1.2 支持选择一个 2.4GHz 或非 DFS 的 5GHz 上游，同时保留两个热点；不是双 Wi-Fi 聚合，断线可能回退蜂窝。旧 v0.1.1 安装包仍为 2.4GHz 上游与 5GHz 下游。USB AUTO 用于上游 WAN，**连接电脑作为下游必须选 LAN**，不是自动猜测电脑角色。

## 本仓库维护的变更

- **国行 B31 支持**：按 B28 / B31 分别校验固件、内核、原厂文件和网页资源指纹，安装目录绑定准备时读取的设备身份；B31 采用 UI 优先启动，首装保持直连，网络协调服务不自动启用。
- **嵌套策略组节点选择**：屏幕和网页会沿当前规则 / 全局流量路径定位到实际承载节点的策略组；网页切换前校验成员，切换后回读确认，无效节点会被拒绝。
- **代理状态与覆盖自检**：屏幕和网页把核心运行状态与上网接管状态分开显示，标注 `MATCH / GLOBAL → 策略组 → 节点` 的当前路径，并可发起只读自检；自检由网络协调脚本回读实际 iptables 规则，明确 UDP 与 IPv6 不代理，并提示 IPv6 可能绕过。订阅列表显示用量、到期与更新超期提示。
- **验证边界分列**：B28 与 B31 分别记录实机证据和未验证项，不把单台设备的验证结果外推到其他固件或所有用户。

## 上游版本能力（v0.1.1 – v0.1.3）

### v0.1.3

新增第三套「海雾玻璃」主题：蓝灰渐变、半透明卡片、浅色文字，保留原有两套主题与操作布局。底部五菜单使用原生绘制图标，不依赖网络或图标字体。通过「设置 → 电源与屏幕 → 界面主题」选择，保存后自动恢复；原厂网页版配色不受此设置影响。

修复休眠后新 UI 启动几秒就退回原厂的问题：看门狗改为检查心跳是否持续推进，避免混用包含/不含休眠时间的时钟；真实卡死仍保留回退保护。玻璃效果为静态 RGB565 合成，没有新增动画或刷新定时器；尚未实测整夜耗电差异。

![海雾玻璃五页预览，使用模拟数据](docs/images/seaglass-five-pages.png)

### v0.1.2

双频中继不再要求关闭自身 2.4G 热点，连接和更换上游合并入口。修复信道切换后“热点能搜到但认证失败”，核对驱动实际信道；修复首页中继标题周期性闪为运营商名称。屏幕菜单支持滑动、记住滚动位置并避免滑动误触。操作与验收边界见 [Wi-Fi 中继说明](docs/WIFI-RELAY.md) 和 [更新记录](docs/CHANGELOG.md)。

### v0.1.1

优化深浅两套主题的文字对比与配色；可操作项前置，电池状态集中到详情，保留未验证功能的限制；网页去除与原厂重复的设置，分类菜单常驻底部，原厂侧栏的增强入口移至末尾。详见 [更新记录](docs/CHANGELOG.md)。

安装器仍用于首次安装，**没有自动覆盖旧版的升级命令**；已有安装请先阅读更新边界，勿删除配置后重装。

原厂网页和字体不再分发：准备工具在 USB 连接时，从目标设备读取固件号、设备标识及三份固定的原厂静态网页文件，验证指纹后生成仅绑定本机的安装目录；包内只保存设备标识摘要，不保存明文 IMEI。安装不改写原厂网页分区。Mihomo、Tailscale 和规则数据从各自官方来源下载，固定版本及 SHA-256 见 `packaging/dependencies.json`。准备目录只留在自己的电脑，**不要上传或转发**。

## 从源码构建

依赖：Zig 0.14.1、Go 1.26.5、Python 3、Git；主机测试还需 C 编译器与 Node.js。官方 Zig/Go 工具链请自行安装。

```sh
sh scripts/build.sh
sh scripts/test.sh
python3 scripts/package.py
```

可通过 `ZIG=/path/to/zig GO=/path/to/go sh scripts/build.sh` 指定编译器。结果位于 `dist/`。源码完整提供；`sdk/stub.c` 仅用于生成链接 SONAME，运行时使用目标设备自己的库，不分发中兴动态库。预编译程序不包含编译机绝对路径。
