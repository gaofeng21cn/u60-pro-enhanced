# U60 Pro Enhanced

为中兴 U60 Pro（MU5250）国行原厂系统提供的**屏幕界面 + 原厂网页功能增强**。保留中兴系统、基带、Wi-Fi 驱动和原厂界面，不是 OpenWrt 固件，也不是整机刷机包。

支持国行 B28（`BD_FLYMODEMMU5250V1.0.0B28`、Linux `5.15.185-perf`）与国行 B31（`BD_CNMU5250V1.0.0B31`、Linux `5.15.194-perf`）。准备工具按目标固件分别校验原厂文件、网页资源指纹和设备身份，未知固件、错配安装包或其他设备都会在写入前被拒绝；两个固件的安装包不能互换使用。

## 项目目标

原厂界面能管理基本网络，但代理、组网和设备状态在日常使用中不够顺手。本项目希望在不改动原厂固件的前提下，把 U60 Pro 变成一个可以独立使用的网络终端：

- 流量是否已经走代理、当前使用哪个节点、命中哪条规则，在屏幕上直接可见、可直接切换；
- 订阅、规则、实时连接等需要更大空间的配置，在原厂网页的「增强功能」里完成；
- 全部操作在设备本机执行，订阅、节点和凭据只留在设备上；
- 任何时候都能双击电源键切回原厂界面，增强功能异常不影响原厂网络和原厂页面。

## 已实现的功能

| 模块 | 新屏幕 UI | 原厂网页版“增强功能” |
|---|---|---|
| 首页与显示 | 五个主页、流量/速率/时间/电池/信号/上游状态、主题和亮度 | 新增能力概览、底部分类导航 |
| Clash / Mihomo | 服务与分流开关、规则/全局模式、节点选择、测速 | 订阅新增/修改/删除/更新、更新间隔、策略组与节点、规则及本地规则、连接查看与关闭；URL 脱敏 |
| Tailscale | 开关、模式、设备、子网互通、出口选择等 | 更完整设备清单、健康/版本/密钥到期、主机名、发布路由、网络诊断；管理端审批仍在 Tailscale 后台 |
| Wi-Fi | 2.4G/5G 分别开关、双热点共存中继、选择/更换上游及保存频段 | 同一中继入口；热点基础设置使用原厂菜单 |
| USB 网口 | 手动 LAN 与 AUTO 上游 WAN 识别、状态与回退 | 同一角色设置与状态 |
| 电源与待机 | 保留电源键操作；充电/直供、待机服务策略与详情 | 同步充电状态和控制；危险能力按本机验收结果锁定 |
| 其他 | 流量账本、蜂窝信息与部分高级设置 | 原厂页面继续承担原有管理功能；增强页不宣称覆盖所有社区端点 |

**边界：** 内置 Mihomo 的透明代理当前覆盖 IPv4 TCP 与 DNS；普通 UDP 与 IPv6 未接管，全面防泄漏和长期负载尚未验证，B28 与 B31 的实机证据分别记录、不互相外推。Tailscale 的双向子网访问需要管理端批准路由和访问策略，不会自动放开账号权限。Wi-Fi 中继支持选择一个 2.4GHz 或非 DFS 的 5GHz 上游，同时保留两个热点；它不聚合双频带宽，上游断开时可能回退蜂窝。USB AUTO 用于上游 WAN，**连接电脑作为下游必须选 LAN**，不是自动猜测角色。

本仓库当前以源码提供，没有对应的公开安装包 Release：请按下文构建，并运行准备工具生成与目标设备固件、设备身份绑定的本地安装目录。上游 [v0.1.3 Release](https://github.com/defilippisprafka-netizen/u60-pro-enhanced/releases/tag/v0.1.3-experimental) 提供仅支持 B28 的现成安装包。

安装包没有任何现成节点、订阅、密码、Tailscale 身份、SSH 私钥或开发机配置。B31 首装保持直连，不自动接管现有 Wi-Fi、USB 网口或代理路由；要使用代理需自行初始化 Clash / Mihomo、添加订阅、选择节点并启用。B28 安装后保持原有启动行为。**不会升级固件、解锁 ADB 或创建云端账户。**

原厂网页和字体不随项目分发：准备工具在 USB 连接时，从目标设备读取固件号、设备标识及三份固定的原厂静态网页文件，验证指纹后生成仅绑定本机的安装目录；包内只保存设备标识摘要，不保存明文 IMEI。安装不改写原厂网页分区。Mihomo、Tailscale 和规则数据从各自官方来源下载，固定版本及 SHA-256 见 `packaging/dependencies.json`。准备目录只留在自己的电脑，**不要上传或转发**。

## 从源码构建

依赖：Zig 0.14.1、Go 1.26.5、Python 3、Git；主机测试还需 C 编译器与 Node.js。官方 Zig/Go 工具链请自行安装，Zig 0.16 会构建失败。

```sh
sh scripts/build.sh
sh scripts/test.sh
python3 scripts/package.py
```

可通过 `ZIG=/path/to/zig GO=/path/to/go sh scripts/build.sh` 指定编译器。结果位于 `dist/`，把设备信息和原厂网页资源绑定进安装目录的准备步骤见[安装与首次配置](docs/INSTALL.md)。

源码完整提供；`sdk/stub.c` 仅用于生成链接 SONAME，运行时使用目标设备自己的库，不分发中兴动态库。预编译程序不包含编译机绝对路径。

## 来源

屏幕五页界面与三套主题、原厂网页的覆盖式增强、双频 Wi-Fi 中继、USB 网口角色、Tailscale 集成和基础电源管理来自 [defilippisprafka-netizen/u60-pro-enhanced](https://github.com/defilippisprafka-netizen/u60-pro-enhanced)。本项目在此基础上增加了国行 B31 支持、按固件与设备身份绑定的准备流程、嵌套策略组下的节点选择修复，以及 B28 / B31 分列的验证记录；通用改进会以 issue / PR 形式同步回上游。
